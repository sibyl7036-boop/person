# 需求文档 — Sibyl 个人动态网页简历

## 引言

本项目为 **Sibyl（王语彤）** 创建一个富有创意的个人动态网页简历（单页应用）。

### 设计风格定位

整体设计风格参考用户提供的参考图片，走 **简约、艺术性、杂志 Editorial** 路线：
- **配色方案**：以 **米白/奶油色（#F5F0EB）** 为主背景，搭配 **深棕色（#5C3D2E）** 作为主文字色，**暗红/酒红色（#8B3A3A）** 作为强调色，**淡黄色（#F5E6C8）** 作为卡片/区块背景色，**墨绿色（#4A5D4A）** 作为点缀色
- **字体风格**：标题使用优雅的衬线体（如 Playfair Display / Noto Serif），正文使用清晰的无衬线体（如 Inter / Noto Sans SC），部分装饰文字使用斜体衬线体营造杂志感
- **布局特点**：大量留白、图文混排、不对称网格布局、引用块装饰（如大引号）、编号标记、分隔线等杂志排版元素
- **动画风格**：克制而精致——以淡入、轻微位移、优雅过渡为主，避免过于花哨的动效，保持艺术感

### 内容概述

网页分为四个核心部分：
1. **Hero 首页** — 打字机效果展示个人标签
2. **Experiences** — 时间轴展示教育背景与实习经历
3. **AI Projects** — 卡片式展示 AI 相关项目经验（从实习经历中提炼）
4. **Capability** — 塔罗牌抽卡展示兴趣爱好与个人特质

## 需求

### 需求 1：整体页面框架与视觉风格

**用户故事：** 作为一名访客，我希望看到一个简约而富有艺术感的个人简历网页，以便对 Sibyl 产生专业且有品味的第一印象。

#### 验收标准

1. WHEN 用户打开网页 THEN 系统 SHALL 展示一个全屏的单页应用（SPA），采用米白/奶油色（#F5F0EB 附近）作为主背景色
2. WHEN 页面加载完成 THEN 系统 SHALL 使用深棕色（#5C3D2E）作为主要文字颜色，暗红/酒红色（#8B3A3A）作为强调色和标题装饰色，淡黄色（#F5E6C8）作为卡片区块背景色
3. WHEN 用户浏览页面 THEN 系统 SHALL 保持杂志 Editorial 排版风格：标题使用衬线体（Playfair Display），正文使用无衬线体（Inter），配合大量留白、不对称布局、引用块装饰等排版元素
4. WHEN 页面各模块之间过渡 THEN 系统 SHALL 使用优雅的分隔线或留白进行区隔，保持视觉节奏感
5. IF 用户使用移动设备访问 THEN 系统 SHALL 提供完整的响应式布局，所有内容在手机和平板上均可正常浏览和交互
6. WHEN 页面滚动或切换模块 THEN 系统 SHALL 提供克制而精致的过渡动画（淡入、轻微位移），避免过于花哨的动效

### 需求 2：顶部导航栏

**用户故事：** 作为一名访客，我希望通过顶部导航栏快速跳转到感兴趣的内容模块，以便高效浏览 Sibyl 的简历信息。

#### 验收标准

1. WHEN 页面加载完成 THEN 系统 SHALL 在页面顶部显示简洁的导航栏，包含个人标识（如"Sibyl"字样）和三个导航标签：「Experiences」「AI Projects」「Capability」，导航栏风格与杂志排版一致（衬线体、深棕色文字）
2. WHEN 用户点击某个导航标签 THEN 系统 SHALL 平滑滚动到对应的内容模块，并以下划线或加粗方式高亮当前激活的导航标签
3. WHEN 用户滚动页面经过不同模块 THEN 系统 SHALL 自动更新导航栏中的高亮状态，反映当前所在模块
4. IF 页面向下滚动超过一定距离 THEN 系统 SHALL 保持导航栏固定在页面顶部（sticky 定位），并添加与主背景色一致的半透明背景

### 需求 8：动画与交互体验

**用户故事：** 作为一名访客，我希望在浏览过程中感受到克制而精致的动画效果，以便获得优雅愉悦的浏览体验。

#### 验收标准

1. WHEN 页面元素进入视口 THEN 系统 SHALL 使用 Intersection Observer API 触发入场动画（淡入 + 轻微上移，持续时间 0.6-0.8s）
2. WHEN 用户在不同模块之间切换 THEN 系统 SHALL 提供平滑的滚动过渡效果（smooth scroll）
3. WHEN 用户与可交互元素互动（悬停、点击） THEN 系统 SHALL 提供即时的视觉反馈（阴影变化、边框颜色加深、轻微缩放等），响应时间不超过 100ms
4. IF 用户设备性能较低或开启了减少动画偏好（prefers-reduced-motion） THEN 系统 SHALL 自动降级动画效果，确保页面仍可正常使用
5. WHEN 动画运行时 THEN 系统 SHALL 使用 CSS 动画或 requestAnimationFrame 实现，确保不影响页面主要内容的渲染性能，保持 60fps 流畅度

### 需求 9：技术实现与性能

**用户故事：** 作为开发者（Sibyl），我希望网站使用纯前端技术实现，代码结构清晰，便于后续维护和部署。

#### 验收标准

1. WHEN 项目构建完成 THEN 系统 SHALL 使用 HTML5 + CSS3 + Vanilla JavaScript 实现，不依赖重型框架（可使用 GSAP CDN 用于塔罗牌翻转动画）
2. WHEN 页面首次加载 THEN 系统 SHALL 在 3 秒内完成首屏渲染（在正常网络条件下）
3. WHEN 代码组织时 THEN 系统 SHALL 将 HTML 结构、CSS 样式、JavaScript 逻辑分离为独立文件（index.html、styles.css、data.js、app.js），保持代码可维护性
4. IF 页面包含图片资源 THEN 系统 SHALL 使用懒加载策略，优先加载视口内的图片
5. WHEN 网站部署时 THEN 系统 SHALL 可作为纯静态网站部署，无需后端服务支持
6. WHEN 项目需要容器化部署 THEN 系统 SHALL 提供 Dockerfile，使用 nginx 作为静态文件服务器

### 需求 10：数据驱动与可维护性

**用户故事：** 作为开发者（Sibyl），我希望所有个人信息内容通过数据配置驱动，以便后续轻松更新内容而无需修改页面结构代码。

#### 验收标准

1. WHEN 项目代码组织时 THEN 系统 SHALL 将所有个人信息（经历、项目、能力卡片等）抽取为独立的 JavaScript 数据配置文件（data.js）
2. WHEN 需要更新个人信息 THEN 系统 SHALL 仅需修改数据配置文件，无需改动 HTML 结构或 CSS 样式
3. WHEN 页面渲染时 THEN 系统 SHALL 通过 JavaScript 动态读取数据配置并渲染对应的 DOM 元素，实现数据与视图分离
4. IF 数据配置中某个模块的条目数量变化 THEN 系统 SHALL 自动适应布局，无需手动调整页面结构
5. WHEN 中国地图数据配置时 THEN 系统 SHALL 将去过的省份列表作为数据配置项，方便后续添加新的旅行目的地
